## 3. 覆盖明细

- 年级：受控词表校验、自由文本拒绝、重命名、被班级引用时删除保护。
- 班级：服务端命名、前端禁止提交 `name`、序号整数与范围、重复序号 409、年级改名级联。
- 科目：受控/同义名校验、重复校验、被任课引用时删除保护、查询服务快照。
- 课时规则：周课时、连堂偏好、禁排时段、时段优先、三开关默认值与独立性、冲突检测。
- 查询服务：`ClassQueryService` 输出班级与年级名称；`SubjectQueryService` 输出科目与规则快照。

## 4. 孤儿与缺口

- 无孤儿用例。
- D05 相关：BD-016/BD-026 的排课引擎生效、`ClassQueryService`/`SubjectQueryService` 在引擎快照中的实际消费，需在 D05 执行轮次验证。
