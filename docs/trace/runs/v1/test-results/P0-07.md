## 5. 边界规则清单

1. `backend/src/shared/**` 不得 import `backend/src/modules/**`。
2. `frontend/src/shared/**` 不得 import `frontend/src/views/**`。
3. 任一后端上下文不得直接 import 其他上下文的 `*.repository.ts` 或 `*.domain.ts`；跨域协作只允许应用服务、查询服务、DTO 或领域事件。

域目标由 `backend/src/modules` 目录自动生成；新增上下文无需维护 ESLint 域清单。
