## 3. 已闭合的设计断言

- `COLUMN_DICTIONARY` 为列名、列序、Sheet、格式化与值的单一来源；页面与导出禁止各维护一套。
- XLSX 只含值；日期 `YYYY-MM-DD`、时间 `HH:mm`、空值为空单元格、首行冻结；文件名 `{维度}_{学期}_{YYYYMMDDHHmm}.xlsx`。
- 1000 行 × 12 列为服务端性能基准，p95 ≤3s；设计态未声称实测。
- `print_template` 定义名称、A4/A3、横纵向、边距、标题、页眉页脚、校徽、预设与乐观版本；预设不可删除。
- 校徽只接受 PNG（签名校验）且解码后 ≤2 MiB；SVG/伪装 PNG 400，超限 413。
- 预览与 render 按同一 `renderKey` 调用同一 HTML 模板与同一 `renderPdf`，返回同一 PDF bytes；受保护 HTML 使用 60 秒一次性 256-bit token。
- 导出与打印写安全审计及对应 outbox 事件；导出不要求二次确认。

## 4. 实现轮次必须执行的验收

1. 导出 1000×12，断言 p95 ≤3s、文件可被 Excel 打开、表头冻结。
2. 逐字段比对导出与页面值，断言列名、顺序、取值一致。
3. 调用预览与打印，断言 PDF 字节完全一致。
4. 上传 2.1MB PNG 断言 413；SVG 断言 400。
5. 删除预设模板断言 409；过期/重复 token 访问断言 401/403。
6. 回填 PDF 生成 `p50/p95`、页数、字节数和 A4/A3/横纵版耗时。
