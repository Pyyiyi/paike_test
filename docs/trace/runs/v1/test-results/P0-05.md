## 2. 逐用例对比

| 用例 | 已定结果（oracle） | 实际结果 | 一致性判定 |
|------|--------------------|----------|------------|
| TC-AU-006 | 仅一个预置 Admin，角色 Admin、状态启用 | `sys_user` 中 `admin` 计数为 1，`role=ADMIN`、`status=ENABLED`、`must_change_password=true`、Argon2id 哈希 | 一致 |
| O-AU-006-LOGIN | 默认凭据可登录 | `admin` + `PAIKE_ADMIN_INITIAL_PASSWORD` 登录返回 200，响应 `mustChangePassword=true` | 一致 |
| TC-AP-017 | D15 输入锚点可构造，供逐格断言 | 固定 UUID 写入模板/版本、学期、年级、A/B 班、数学/英语、张/李、301、四条任课与英语禁排规则；重复执行计数不变 | 一致（输入侧） |

## 3. 实现结果

- `npm run db:seed` 自动应用待执行迁移，然后事务性写入管理员与 `seed-anchors.sql`。
- 管理员密码优先取 `PAIKE_ADMIN_INITIAL_PASSWORD`；未设置且首次创建时随机生成并在控制台仅输出一次。
- 重复 seed 保留现有密码与改密状态，只确保唯一 `admin` 为 `ADMIN` / `ENABLED`。
- `seed-anchors.sql` 的领域表守卫改为基于当前 `search_path`；固定 UUID 常量未改变。
- D15 领域表未创建时跳过第二节并输出 NOTICE；领域迁移完成后重复执行即可补齐。
