# Seed 锚点清单（D05 输入基准）

> 来源：仓库根目录 `seed-anchors.sql`。所有 UUID 固定，重复执行不得改变语义。
> `npm run db:seed` 会先运行待应用迁移，再幂等写入管理员、受控词表；领域表存在时同时写入 D15 锚点。

## 1. 预置管理员

| 字段 | 值 |
|------|----|
| `user_id` | `00000000-0000-4000-8000-000000000100` |
| `username` | `admin` |
| `role` | `ADMIN` |
| `status` | `ENABLED` |
| `must_change_password` | `true` |

初始密码只由 `PAIKE_ADMIN_INITIAL_PASSWORD` 提供，或在该变量为空且首次创建管理员时随机生成。随机密码仅在 `npm run db:seed` 控制台输出一次；重复 seed 不会重置已有管理员密码。

## 2. 受控词表

| 类型 | UUID 范围 | 内容 |
|------|-----------|------|
| `GRADE` | `...0120`–`...0122` | 七年级、八年级、九年级 |
| `SUBJECT` | `...0130`–`...0138` | 语文、数学、英语、物理、化学、生物、体育、音乐、美术 |
| `SUBJECT_SYNONYM` | `...0140`–`...0145` | 语/语文课、数/数学课、英/英语课，分别指向规范科目名 |
| `VENUE` | `...0150`–`...0154` | 301、实验室1、音乐教室、美术教室、操场 |

### 四条任课

| 任课 UUID | 班级 | 科目 | 教师 | 周课时 | 场地 | 约束 |
|-----------|------|------|------|:------:|------|------|

科目规则 UUID `00000000-0000-4000-8000-000000000110`：英语禁排周三第 3–4 节。

D15 断言口径：附件 A 为 6 列 × 5 行 = 30 个表格格（6 个表头格 + 24 个数据坐标）；24 个 `(classId,weekday,period)` 坐标逐格比较 `subjectId/teacherId/venueId/null`。

## 4. 使用约定

- D05 及后续测试只引用上述固定 UUID，不依赖插入顺序或自增 ID。
- 锚点不得被测试删除；测试写入应使用独立事务并回滚。
- D15 领域表尚未创建时，seed 会给出 NOTICE 并跳过第二节；领域迁移完成后重复执行即可补齐。
