# 登录、改密与错误页文案（P0-08）

> 覆盖 `/login`、`/change-password`、`/403`、`/404` 与全局 401 会话失效处理。
> 所有文案为面向用户的最终口径；不展示账号存在性、错误码、HTTP 状态码、SQL 或堆栈。

## 1. 登录页 `/login`

| 区域 | 文案 |
|------|------|
| 标题 | 登录工作台 |
| 说明 | 请使用学校分配的账号登录。 |
| 用户名 | 用户名 / 请输入用户名 |
| 密码 | 密码 / 请输入密码 |
| 提交按钮 | 登录系统 |
| 凭据错误 | 用户名或密码错误 |
| 字段为空 | 请输入用户名 / 请输入密码 |
| 锁定 | 登录失败次数过多，请 N 分钟后再试 |
| 会话失效 | 登录已失效，请重新登录 |
| 改密成功 | 密码修改成功，请重新登录 |

规则：

- 账号不存在、密码错误、未知用户名均只显示「用户名或密码错误」。
- 锁定使用服务端 `Retry-After` 秒数在页面内倒计时；锁定期内登录按钮禁用，倒计时结束后恢复。
- 用户名与密码输入均设置 `autocomplete="off"`；密码框提供显示/隐藏切换。
- 不展示演示账号、默认密码、测试凭据或一键填充入口。

## 2. 改密页 `/change-password`

| 模式 | 标题 | 说明 |
|------|------|------|
| 强制改密 | 请先修改初始密码 | 首次登录需要设置新密码。修改成功后，当前登录会话将失效，请使用新密码重新登录。 |
| 主动改密 | 修改登录密码 | 定期更换密码有助于保护账号安全。修改成功后，当前登录会话将失效，请使用新密码重新登录。 |

| 区域 | 文案 |
|------|------|
| 当前密码 | 当前密码 |
| 新密码 | 新密码 |
| 确认新密码 | 确认新密码 |
| 策略标题 | 密码策略 |
| 长度规则 | 至少 8 个字符 |
| 类别规则 | 大写字母、小写字母、数字、符号至少包含 3 类 |
| 新旧关系 | 不能与当前密码相同 |
| 确认关系 | 两次输入的新密码一致 |
| 提交按钮 | 保存并重新登录 |
| 主动模式返回 | 返回工作台 |
| 校验错误 | 请输入当前密码 / 请输入新密码 / 请再次输入新密码 / 两次输入的新密码不一致 / 新密码不能与当前密码相同 |

规则：

- 策略清单随输入实时更新，已满足项显示通过状态。
- 强制模式不提供离开改密页的工作台入口；其他受保护路由由前端守卫和服务端强制改密守卫共同拦截。
- 主动模式可从右上角用户菜单进入，并提供「返回工作台」。
- 改密成功后服务端撤销当前会话，前端清空会话并跳转 `/login?reason=password-changed`，必须使用新密码重新登录。

## 3. 403 / 404

| 页面 | 标题 | 原因说明 | 返回入口 |
|------|------|----------|----------|
| 403 | 您没有权限访问此页面 | 当前账号不能查看该功能，请联系教务管理员确认角色权限。 | 返回上一页 / 返回工作台 |
| 404 | 页面不存在 | 您访问的页面可能已移动或删除，请返回工作台继续操作。 | 返回上一页 / 返回工作台 |

## 4. 角色落地与会话规则

| 场景 | 行为 |
|------|------|
| Admin 登录成功 | 默认落地 `/` |
| Teacher 登录成功 | 默认落地 `/me/timetable` |
| `mustChangePassword=true` | 优先跳 `/change-password`；直接访问 `/semesters` 等受保护路由被弹回改密页 |
| 主动修改密码 | 已登录用户可访问 `/change-password`；成功后重新登录 |
| 角色不符 | 前端守卫跳 `/403`；服务端仍以 RBAC 为最终边界 |
| 受保护页任意 401 | 清空本地会话，跳 `/login?redirect=<原完整路径>&reason=session-expired`，提示「登录已失效，请重新登录」 |
| 登录接口返回 401 | 留在登录页并显示统一凭据错误，不触发会话失效跳转 |
