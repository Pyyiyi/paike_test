## 4. 关键决策

1. **信任层级**：PRD > 原型 > DDD > 裁决；原型仅界面参考，演示登录、需求面板、页面切换器、模拟排课、假数据全部剔除。
2. **架构**：模块化单体；5 个限界上下文（registry/resource/timetable/governance/identity）+ 2 个应用模块（exchange/statistics）。
3. **并发**：采纳 H-01 A，方案级乐观版本 + 409 刷新提示，零部分写入。
4. **安全**：采纳 H-02 A；登录/强制改密/锁定/会话完整设计，界面文案中文友好。
5. **性能**：H-03 固定 50 班数据集，排课 p95 ≤5s，导出 p95 ≤3s。
6. **D15**：唯一公共断言基准；固定种子 + 稳定排序；30 格逐项比对。
7. **存档/切换**：governance 编排 registry/timetable 生命周期服务，不跨域直写。
8. **测试对比**：每卡「已定结果 vs 设计预期」；11 条整体孤儿与 3 条永久孤儿显式登记，不计覆盖。
