### 11.2 后端 registry 模块

- 模板：列表/新建/删除（引用保护）、版本列表/新建/详情/校验 7 个端点。
- 事件：`bc.registry.semester.created`、`bc.registry.semester.status-changed`、`bc.registry.schedule-template.version-created` 与业务同事务写入 outbox。
- `SemesterLifecycleService` 仅导出 `archive(tx, …)` / `switchCurrent(tx, …)` 原语，不暴露存档/切换端点；D07 在同一事务内编排排课方案归档与快照。

### 11.3 状态推导（A-01）

- 对外四值：`NOT_STARTED` / `IN_PROGRESS` / `ENDED` / `ARCHIVED`。
- 存储只保留 `ARCHIVED`；其余三值由 `start_date`、`end_date` 与 `Clock.today()`（Asia/Shanghai）实时推导。
- `ARCHIVED` 为终态：日期变化不回到进行中/已结束；存档学期 PATCH/DELETE/校历写返回 `409 STATE_CONFLICT`，GET/导出可用。
- 日期编辑导致派生状态变化时写入 `status-changed` 事件；存档由 `SemesterLifecycleService.archive` 写事件与日志。

### 11.4 节次校验（A-08）

- 编号从 1 连续、无跳号/重复；`startTime < endTime`；`HH:mm` 落在 `00:00-23:59`；同一开放星期内两节时间不重叠；`openWeekdays` 为 1-7 非空子集。
- 违反规则返回 `400 VALIDATION_ERROR`，`details` 携带 `periods` / `periods.N.startTime` / `periods.N.endTime` 等字段级错误，事务回滚不插入版本。
